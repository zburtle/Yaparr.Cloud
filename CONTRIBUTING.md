# Contributing to Yaparr.Cloud

Pull requests are welcome. A few things to know first:

- **Agree to the [Contributor License Agreement](CLA.md).** Put the sentence *I agree to the Yaparr.Cloud Contributor License Agreement* in the description of your pull request (the pull request template has it). You keep the copyright in what you write; the agreement lets the project use it under other licences too, for example in a commercial or hosted edition. Pull requests without it will not be merged.
- The code is licensed under the [AGPL-3.0](LICENSE).
- Run `dotnet test` before you open the pull request. Changes to how sign-in, tokens or backups work need a test.
- Report security problems privately, through the repository's "Report a vulnerability" button (Security tab), not in a public issue.
- Everything merged to `master` is deployed automatically to the hosted service, so the maintainer reviews every pull request.
